# Лабораторная 10: стенд диагностики

Преподаватель создает PKI через `scripts/generate-lab-pki.sh`, затем запускает
`sudo setup-server.sh ../../generated/pki`. Private key устанавливается
`root:lpic103-tls` mode 0640: сервис читает его, остальные пользователи — нет.

Для упражнения внесите **ровно один** дефект: неверная A-запись, закрытый порт,
остановленный unit, неверный listener address или сертификат другого имени.
Зафиксируйте дефект, чтобы после диагностики вернуть исходное состояние. Клиент
использует адаптированную копию `check-endpoint.sh.template`; успешный итог —
DNS, TCP, TLS/name/trust и HTTP одновременно.
