## Полнота конфигураций

Samba/BIND/Nginx/PHP-FPM/SSH представлены полными файлами, а не инструкцией
добавить неизвестный блок к неизвестному package config. Все скрипты и
существенные параметры прокомментированы. Для platform-dependent вариантов
указаны package/unit/user/path и команды установки.

Полные systemd drop-in, sysctl.d и exports.d остаются небольшими файлами:
это штатные самостоятельные единицы конфигурации. Установленные пакетами
модули и MIME tables берутся из подписанных репозиториев ОС.
Генераторы создают уникальные secrets/host-specific файлы в закрытом каталоге,
не публикуют универсальные private keys.

Корневые исторические материалы сохранены для совместимости.
Для выполнения курса выбирайте канонический README соответствующей лабы;
ISC DHCP в старой лекции не означает наличие dhcpd в Rocky10.

## Проверки

```bash
./scripts/validate-materials.sh
```

Дополнительные профильные проверки в одноразовых контейнерах описаны в
VERIFICATION.md. Они устанавливают пакеты внутри контейнера и подключают
репозиторий read-only. Реальные L2 DHCP, hardware FIDO2, reboot/systemd,
SELinux и операции с дисками требуют отдельных ВМ по сценариям лабораторных.
