# OpenVAS / Greenbone: архивная заметка

OpenVAS отсутствует в актуальных презентации v3 и лабораторном руководстве v4
MT_LPIC-103. Старые команды установки и имена services удалены: они зависели от
конкретного стороннего репозитория и не соответствовали единой пакетной схеме.

Если преподаватель возвращает эту тему, стенд следует готовить отдельной
версированной инструкцией для выбранного Greenbone Community Edition и точной ОС.
Обязательны: проверка источника пакетов/образов, изолированная scan target network,
обновление feeds, ограничение web UI сетью управления и запрет сканирования систем
без явного разрешения владельца.
